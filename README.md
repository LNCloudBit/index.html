# 📊 Endividômetro — Diagnóstico Financeiro Interativo

Ferramenta web interativa desenvolvida como página de captura (landing page) e diagnóstico financeiro em tempo real para o e-book e workbook **"Endividado, Porém Investindo"**.

## 🎯 Sobre o Projeto

O **Endividômetro** é um teste rápido de 4 perguntas que mede o nível de sufoco e estresse financeiro do usuário (escala de 0 a 10). Com base nas respostas, a aplicação calcula instantaneamente um diagnóstico cirúrgico dividido por níveis de alerta (Verde, Amarelo e Vermelho) e direciona o leitor para a solução prática: o guia de finanças e investimentos sem ilusões.

### ✨ Principais Funcionalidades
* **Quiz Dinâmico:** 4 etapas intuitivas focadas na rotina real de quem trabalha duro (faturas, imprevistos, orçamento mensal e inteligência emocional).
* **Velocímetro Animado:** Indicador visual em SVG com ponteiro de precisão, blocos coloridos e numeração limpa nas extremidades.
* **Diagnóstico Personalizado:** Resposta imediata com orientações práticas para estancar o sangramento e construir uma reserva de emergência.
* **Call to Action (CTA) Integrado:** Botão de alta conversão direcionando diretamente para o checkout oficial na Kiwify.

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído de forma leve e rápida, sem dependências complexas, ideal para carregamento instantaneyo em dispositivos móveis:
* **HTML5 & CSS3**
* **Tailwind CSS** (via CDN para estilização moderna e responsiva)
* **JavaScript Puro (Vanilla JS)** para a lógica do quiz, cálculo de pontuação e animação fluida do velocímetro.
